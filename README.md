Part 2：每日自動晨報（背景自動跑，不用你動手）
為什麼要做這層？
-	你不用每天手動問 AI，也不用擔心 Claude 對話 token 用完
-	Gemini API 免費額度一天用 1 次完全足夠
-	產生的報告會存成 report.json，戰情室網頁可以直接讀取顯示（目前網頁還沒接這段顯示邏輯，如果你要我再幫你加）
需要準備的東西
1.	GitHub 帳號（免費）+ 一個新的 repository
2.	FinMind Token：finmindtrade.com 免費註冊
3.	Gemini API Key：aistudio.google.com 免費申請
設定步驟
1. 建立 GitHub repo，放入以下檔案：

你的repo/

├── daily_report.py          ← 我給你的腳本

├── .github/

│   └── workflows/

│       └── daily-report.yml ← 我給你的排程設定

└── index.html                ← 就是戰情室-林義凱版.html（改名）

2. 設定 API 金鑰（重要：不要直接寫在程式碼裡！） 到你的 repo → Settings → Secrets and variables → Actions → New repository secret，新增兩組：

-	FINMIND_TOKEN
-	GEMINI_API_KEY

3. 開啟 GitHub Pages（讓網頁能被瀏覽） Repo → Settings → Pages → Source 選 main branch → 存檔， 之後會得到一個網址，例如：https://你的帳號.github.io/repo名稱/

4. 測試自動化 Repo → Actions → 選 "Daily Investment Report" → 右邊 "Run workflow" 手動觸發一次， 確認能成功產生 report.json 且沒有錯誤。

之後就會照排程（每天台灣時間早上 8:30）自動執行，完全不用你管。
